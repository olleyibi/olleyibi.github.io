# Ibidamola Olley — portfolio

Personal portfolio for data analytics, data science, Power BI and Microsoft solutions.

Website: https://olleyibi.github.io/

## Hosting and updates

GitHub Pages publishes the root of the codex/github-pages branch. The .nojekyll file keeps this a plain static HTML, CSS and JavaScript website. No build server, ChatGPT account, AI API key or paid runtime is needed.

Edit index.html for Home; work/index.html, experience/index.html and training/index.html for the other main pages. The project-*/index.html files contain the project stories. Styles and scripts live at the repository root, and public images live in assets/. Push changes to codex/github-pages to publish them. Keep root-level .html redirect files for older links.

IBI uses curated jokes and browser animations. It changes jokes every 30 seconds and when clicked, with pause, hide and reduced-motion support. It does not send conversations to an AI service.

## Content

This repository contains the public portfolio, optimized portrait, resume and illustrative project graphics. Project illustrations use fictional data. Private client files and source datasets are not included.

The optional DM Sans font loads from Google Fonts, with system font fallbacks.
